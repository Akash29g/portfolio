I built my portfolio as a pull request, and ran it on AWS

October 31, 2026

Most portfolios list skills. I wanted mine to behave like my work, so the whole site is a pull request titled "feat: hire Akash Goswami". The visitor is the reviewer, the tabs are Conversation, Files changed, Commits and Checks, and the big green button at the bottom merges me into your team.

The frontend

The site is plain HTML, CSS and JavaScript with no framework. It is hosted on AWS Amplify Hosting, which serves it through CloudFront and redeploys on every git push.

The backend

One HTTP API in API Gateway fronts a single Lambda function with three routes. The first powers Ask the reviewer: it calls Amazon Bedrock with a system prompt made of facts about me, so it answers only from what I wrote. The second is the merge button, which starts a Step Functions Express workflow that validates, records the merge in DynamoDB and notifies me through SNS. The third is the contact form, which stores the message in DynamoDB and emails it to me with SES.

Why an Express workflow

Express workflows can run synchronously, so the API call can wait for the result and return the merge count to the page. A Standard workflow would be better for long jobs, but this is three quick steps.

Keeping it cheap and safe

Everything is pay per request. The API is throttled, inputs are validated and length limited, CORS is locked to my domain, and the infrastructure lives in a SAM template so it can be redeployed or deleted in one command.

The fun parts

There is a hidden terminal on the slash key, a Konami code, and Pipeline Grand Prix, a small kart game where each lap is a pipeline stage. See the AWS page for the architecture and my Well-Architected self-review.
