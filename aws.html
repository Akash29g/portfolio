How this site runs on AWS (click a service)

Well-Architected self-review (scored by me, 5 is best)

Operational excellence 3/5Backend is infrastructure as code (SAM), site redeploys on every git push. Next: CloudWatch alarms.
Security 4/5Separate IAM roles, input validation, CORS locked to my domain, no secrets in code. Next: WAF.
Reliability 3/5Managed serverless services, and the race game still works if the API is down.
Performance efficiency 4/5Static site on CloudFront, a small Bedrock model, on-demand DynamoDB.
Cost optimization 4/5Pay per request everywhere, throttled API, budget alert on the account.
Sustainability 3/5Serverless scales to zero, so there are no idle servers.
