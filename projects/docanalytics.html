ShippedSoftware Developer Intern, AVEVA Hyderabad, Jun to Aug 2026

The project

DocAnalytics is a multi-tenant document-processing analytics platform. I designed and built it end to end, from data modeling to deployment, and it runs in production under a custom domain.

.NET 10Angular 22 SignalsPostgreSQLEF CoreAWS BedrockS3TerraformECSGuardDuty

Key decisions

Tenant isolation

Every tenant's data is separated using EF Core global query filters, backed by role-based authorization, so a missing WHERE clause cannot leak data across tenants.

AI invoice extraction you can trust

Invoices go through a pipeline on AWS Bedrock and S3. Instead of trusting model output blindly, the pipeline reconciles subtotals against totals automatically, which gave about 98% extraction confidence.

Safe uploads

Uploaded files are scanned for malware with AWS GuardDuty before they are processed.

Infrastructure as code

Production AWS infrastructure (ECS, ALB, RDS, ECR) is provisioned with Terraform and shipped through a CI/CD pipeline gated on test coverage, gitleaks and Trivy scans, with API rate limiting in front.

Quality and results

  • Test-driven development with xUnit on the backend and Vitest on the frontend.
  • JMeter load tests confirmed sub 3 second responses with 0% errors at 1M+ record scale.
  • Security gates run on every change, not just before release.
